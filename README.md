# Мем-радар: самые популярные мемы в Telegram

Бот раз в 4 часа присылает вам в Telegram подборку мемов, которые сейчас «залетают».
Работает бесплатно на GitHub, без вашего ПК, сервера и **без входа в ваш аккаунт Telegram**.

**Откуда берёт мемы**
- Публичные Telegram-каналы (RU, UA, EN) через открытую веб-версию `t.me/s/канал`. Её видно любому без входа.
- **Lemmy**: открытая альтернатива Reddit, зарубежные мемы, ключи не нужны.
- **Reddit**: по желанию, если получите бесплатные ключи (шаг 8).

**Как определяется «залёт»**: каждый пост сравнивается с обычными просмотрами своего канала.
Мем с просмотрами в 5 раз выше нормы канала получает «залёт ×5.0» и попадает в топ, даже если канал маленький.

---

## Что понадобится

- Telegram на телефоне
- компьютер для первой настройки (с телефона тоже можно, но неудобно)
- 20–30 минут

---

## Шаг 1. Создайте бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, `Мем-радар`) и юзернейм, оканчивающийся на `bot` (например, `alex_memradar_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH...`. Сохраните его: это пароль от бота.
4. Откройте своего нового бота и нажмите **Start** (отправьте `/start`). **Обязательно**: без этого бот не сможет вам писать.

## Шаг 2. Узнайте свой Telegram ID

Откройте **@userinfobot** и нажмите Start. Он пришлёт число в строке `Id`, например `123456789`. Сохраните его.

## Шаг 3. Создайте репозиторий на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта ещё нет.
2. Справа вверху **+** → **New repository**.
3. Repository name: `memradar`.
4. Выберите **Public**. Для публичных репозиториев GitHub Actions бесплатны без ограничений.
   Секреты (токен, ID) при этом никто не видит, они хранятся отдельно и зашифрованы.
5. Нажмите **Create repository**.

## Шаг 4. Загрузите файлы

1. Распакуйте архив `memradar.zip` на компьютере.
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Откройте распакованную папку `memradar`, выделите **всё её содержимое** и перетащите в окно браузера:
   `memradar.py`, `scoring.py`, `sources.json`, `state.json`, `requirements.txt`, `README.md`,
   папки `worker` и **`.github`**.
   - На Mac папка `.github` скрыта: в Finder нажмите `Cmd + Shift + .`, чтобы её увидеть.
4. Внизу нажмите **Commit changes**.
5. **Проверьте**: в репозитории должна быть папка `.github` → `workflows` → `memradar.yml`.

   Если папка `.github` не загрузилась: **Add file** → **Create new file**, в поле имени введите
   `.github/workflows/memradar.yml` (слэши создадут папки), вставьте содержимое этого файла из архива → **Commit changes**.

## Шаг 5. Добавьте секреты

В репозитории: **Settings** → слева **Secrets and variables** → **Actions** → **New repository secret**.

Создайте два секрета:

| Name | Secret |
|---|---|
| `BOT_TOKEN` | токен из шага 1 |
| `OWNER_ID` | ваш ID из шага 2 |

## Шаг 6. Разрешите боту сохранять настройки

**Settings** → **Actions** → **General** → внизу блок **Workflow permissions** →
выберите **Read and write permissions** → **Save**.

Это нужно, чтобы бот запоминал уже присланные мемы и изменения списка каналов.

## Шаг 7. Первый запуск и проверка

1. Откройте вкладку **Actions**. Если GitHub спросит, нажмите **I understand my workflows, go ahead and enable them**.
2. Слева выберите **Мем-радар** → справа **Run workflow** → в поле «Что сделать» выберите **test** → зелёная кнопка **Run workflow**.
3. Через 1–2 минуты бот пришлёт **отчёт**: сколько постов удалось прочитать с каждого источника.
   Каналы с `0` либо закрыли веб-версию, либо ничего не публиковали за сутки, их можно убрать кнопкой ➖ Удалить источник.
4. Снова **Run workflow**, режим **digest**: придёт первая подборка мемов.
5. Отправьте боту `/start`: через 10–20 минут появится меню с кнопками (с мгновенным режимом — через минуту).

Готово. Дальше всё работает само: **каждые 4 часа** приходит подборка.
Первый автоматический запуск по расписанию GitHub иногда делает с задержкой до часа, это нормально.

## Как пользоваться

### Подборка сейчас, по запросу
- **С телефона**: установите приложение **GitHub** → ваш репозиторий → **Actions** → **Мем-радар** → **Run workflow**.
  Мемы придут через 1–2 минуты. Можно выбрать язык, количество и «только видео».
- **Кнопкой в чате с ботом**: 🔥 Топ за сутки. Бот проверяет чат раз в 10 минут, так что ответ придёт через 10–20 минут.
  Чтобы бот отвечал за минуту, настройте «мгновенный режим» (шаг 9).

### Кнопки

Отправьте боту `/start`: внизу чата появится меню.

| Кнопка | Что делает |
|---|---|
| 🔥 **Топ за сутки** | лучшие мемы за 24 часа |
| ⚡ **Залетает сейчас** | что набирает обороты за последние 4 часа |
| 🎬 **Только видео** | для вставок в монтаж |
| 📋 **Источники** | список всех каналов, сообществ Lemmy и сабреддитов |
| ➕ **Добавить источник** | бот попросит прислать ссылку на канал (`t.me/…` или `@…`), сообщество Lemmy (`memes@lemmy.world`) или сабреддит (`r/memes`). Для Telegram-канала потом спросит раздел: 🇷🇺 RU, 🇺🇦 UA или 🇬🇧 EN |
| ➖ **Удалить источник** | список кнопок `❌ @канал`: нажали, и источник удалён |
| ⚙️ **Настройки** | как часто присылать (2–24 ч), сколько мемов, пауза, проверка источников, сброс истории |
| ❓ **Помощь** | краткая справка |

После каждой подборки внизу есть кнопки «Ещё»: 🇷🇺 RU · 🇺🇦 UA · 🇬🇧 EN · 🎬 Видео · ⚡ Свежак.

**Быстрое добавление канала**: просто пришлите боту ссылку на канал (`t.me/имя` или `@имя`), без всяких кнопок.

> ⏳ Без мгновенного режима (шаг 9) бот проверяет чат раз в 10 минут, поэтому ответ на нажатие приходит
> в течение 10–20 минут. С мгновенным режимом — за 1–2 минуты.

<summary>Те же действия текстовыми командами</summary>

| Команда | Что делает |
|---|---|
| `/top` | топ за сутки; `/top 5 ua`, `/top en` |
| `/hot` · `/video` | залетает сейчас · только видео |

| `/add @канал ru` | добавить канал сразу в раздел |
| `/add memes@lemmy.world` · `/add r/memes` | добавить Lemmy или Reddit |

| `/every 4` · `/count 8` | каждые N часов · сколько мемов |
| `/pause` · `/resume` · `/reset` | пауза · включить · забыть историю |

### Изменить источники вручную
Откройте в репозитории файл `sources.json` → карандаш ✏️ (Edit) → поправьте списки → **Commit changes**.
Канал добавляется без `@`, в кавычках, через запятую.

**Канал подходит, только если у него открыта веб-версия**: откройте в браузере `https://t.me/s/имя_канала`.
Если видны посты, бот его прочитает.

## Шаг 8 (по желанию). Reddit

Без Reddit зарубежные мемы берутся из Lemmy и EN-каналов Telegram. Чтобы добавить Reddit:

1. Войдите на reddit.com и откройте [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps).
2. **create another app** → name: `memradar` → тип **script** → redirect uri: `http://localhost:8080` → **create app**.
3. Строка под названием приложения — это **client id**, поле `secret` — **client secret**.
4. Добавьте секреты в GitHub (как в шаге 5): `REDDIT_CLIENT_ID` и `REDDIT_CLIENT_SECRET`.

Reddit периодически ужесточает доступ к API. Если ключи не выдаются или бот пишет «ключи не подошли»,
просто пропустите этот шаг.

## Шаг 9 (по желанию). Мгновенные ответы на команды

По умолчанию бот проверяет команды раз в 10 минут. Чтобы кнопки срабатывали за 1–2 минуты,
поставьте бесплатный посредник на Cloudflare (около 15 минут).

**9.1. Токен GitHub**
1. GitHub → ваш аватар → **Settings** → внизу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Token name: `memradar`. Expiration: 1 год (или No expiration).
3. Repository access: **Only select repositories** → `memradar`.
4. Permissions → **Actions**: **Read and write**.
5. **Generate token** → скопируйте (показывается один раз).

**9.2. Воркер Cloudflare**
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages** → **Create** → **Create Worker** → **Deploy**.
3. **Edit code** → удалите всё → вставьте содержимое файла `worker/worker.js` → **Deploy**.
4. Запомните адрес воркера, вида `https://memradar.ваше-имя.workers.dev`.
5. Вкладка воркера **Settings** → **Variables and Secrets** → добавьте (тип Secret):

| Name | Value |
|---|---|
| `BOT_TOKEN` | токен бота |
| `OWNER_ID` | ваш ID |
| `GH_TOKEN` | токен из 9.1 |
| `GH_REPO` | `ваш-логин-github/memradar` |
| `HOOK_SECRET` | любая строка из латинских букв и цифр, 20+ символов |

**9.3. Подключите бота к воркеру**
Откройте в браузере ссылку, подставив свои значения:
```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_ВОРКЕРА>&secret_token=<HOOK_SECRET>
```
Должно появиться `"Webhook was set"`. Нажмите в боте 🔥 Топ за сутки: он сразу ответит «⏳ Собираю мемы»,
а через 1–2 минуты пришлёт подборку.

Отключить мгновенный режим: откройте `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook`.
Бот вернётся к проверке раз в 10 минут.

## Безопасность

- **Ваш аккаунт Telegram не используется**: бот читает только публичные веб-страницы каналов и пишет через Bot API.
- Токен бота храните **только в секретах**, не вставляйте его в файлы репозитория.
  Если токен утёк: @BotFather → `/revoke` → новый токен → обновите секрет.
- В публичном репозитории видно только список каналов и номера уже присланных постов. Ничего личного там нет.
- Бот отвечает только вам (по `OWNER_ID`), остальным пишет «Это личный бот».

## Если что-то не работает

Откройте **Actions** → последний запуск → шаг **Запуск**: там понятным текстом написано, что произошло.

| Проблема | Решение |
|---|---|
| «Нет BOT_TOKEN» | шаг 5: проверьте имя секрета, буква в букву |
| Ошибка в шаге «Сохранить состояние» (403) | шаг 6: включите Read and write |
| Бот молчит | вы нажали Start у бота (шаг 1.4)? Верный ли `OWNER_ID`? |
| У канала 0 постов в проверке | у канала нет веб-версии или он не постит: ➖ Удалить источник |
| Рассылка остановилась | GitHub отключает расписание после 60 дней без изменений в репозитории. Бот сам обновляет `state.json` с каждой подборкой, так что обычно это не случается. Если всё же случилось: Actions → Мем-радар → **Enable workflow** |
| Подборка пришла с опозданием | GitHub запускает расписание с задержкой 5–30 минут, это нормально |
